# TSF Connect Bootstrap — модель доверия

## Репозитории

- `SCORP365/TSF` — публичный загрузчик, QR-авторизация GitHub Device Flow и документация.
- `SCORP365/TSF-Connect` — приватный исходный код и единый установщик.

## Порядок работы

1. Оператор запускает публичный bootstrap из заранее проверенного полного commit SHA.
2. Bootstrap показывает GitHub verification URL, одноразовый код и QR-код.
3. Оператор подтверждает доступ через GitHub Device Flow.
4. Временный токен используется только в HTTPS Authorization headers для чтения приватного репозитория.
5. Bootstrap загружает архив по полному commit SHA, закреплённому в исходнике bootstrap.
6. До запуска проверяет структуру архива: запрещает абсолютные пути, `..`, ссылки, специальные файлы, чрезмерные размеры и подозрительное число файлов.
7. Запускается только единый `installer/install.sh` из полученного архива.
8. Токен не передаётся установщику и не сохраняется на диск.

## Доверие и ограничения

Проект не использует обязательную Ed25519-подпись релизов. Доверие основано на приватности GitHub-репозитория, защите GitHub-аккаунта и GitHub App, доступе через Device Flow, точном неизменяемом SHA коммита и проверках CI.

SHA-256 архива вычисляется для контроля и журналирования, но сам по себе не доказывает подлинность, если ожидаемое значение не получено из независимого доверенного источника. Поэтому его нельзя называть цифровой подписью или защитой от компрометации GitHub.

Изменение исходного кода требует прохождения CI и обновления закреплённого SHA в bootstrap. Первоначальный bootstrap также необходимо получать по заранее проверенному commit SHA. Основная ветка не должна обновляться автоматически.

## GitHub App

GitHub App использует Device Flow. Client ID является публичной конфигурацией. PAT, Client Secret и интерактивный `gh auth login` не требуются.

## Не входит в задачу

Bootstrap не должен менять DNS, firewall, ISPmanager, Nginx, TLS, SSH, почту или посторонние службы в ходе авторизации. Production deployment выполняется только после изолированной проверки и отдельного разрешения оператора.
