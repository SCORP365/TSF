# TSF Connect Bootstrap

Публичный загрузчик для получения приватного установщика TSF Connect.

## Как работает установка

1. Bootstrap запускается из проверенного коммита публичного репозитория.
2. Показывает QR-код и одноразовый код GitHub Device Flow.
3. После подтверждения получает временный доступ только к приватному репозиторию `SCORP365/TSF-Connect`.
4. Загружает архив по полному неизменяемому SHA коммита, закреплённому в `bootstrap/installer_flow.py`.
5. Проверяет структуру архива и безопасно извлекает только обычные файлы и каталоги.
6. Запускает единый `installer/install.sh`; GitHub-токен установщику не передаётся и на диск не сохраняется.

## Модель доверия

Для проекта используется простая модель: приватный GitHub-репозиторий, ограниченный доступ через GitHub Device Flow, точный SHA коммита и обязательные проверки CI. Обязательная Ed25519-подпись релизов не используется.

SHA-256 загруженного архива вычисляется и показывается для контроля и журналирования. Это не независимая цифровая подпись и не защита от злоумышленника, который получил возможность менять сам приватный репозиторий. Доверие к исходникам основано на защите GitHub-аккаунта, GitHub App и приватного репозитория.

Закрытый ключ Ed25519 не требуется для установки. Ранее созданную пару можно оставить в личном резерве; она не участвует в работе bootstrap.

## Обновление версии исходников

После прохождения CI в приватном репозитории:
- зафиксировать полный 40-символьный SHA проверенного коммита;
- обновить `SOURCE_COMMIT` в `bootstrap/installer_flow.py`;
- прогнать тесты bootstrap;
- проверить сквозной сценарий в изолированной Ubuntu 24.04;
- только после отдельного разрешения готовить изменения в основных ветках и production.

## Запуск

Получайте публичный bootstrap по конкретному проверенному commit SHA, а не из плавающей ветки:

```sh
git clone https://github.com/SCORP365/TSF.git /tmp/tsf-bootstrap
cd /tmp/tsf-bootstrap
git checkout FULL_VERIFIED_BOOTSTRAP_COMMIT_SHA
sudo bash bootstrap/run.sh
```

Для проверки получения исходников без запуска установщика используйте `sudo bash bootstrap/run.sh --retrieve-only`. Для продолжения прерванной установки — `sudo bash bootstrap/run.sh --resume`.

## Ограничения

- Не использовать PAT или Client Secret.
- Не сохранять GitHub-токен на сервере.
- Не загружать исходники из плавающей ветки.
- Не запускать исходники до проверки CI и проверки архива на безопасные пути и типы файлов.
- Не менять DNS, firewall и посторонние службы во время авторизации.
- Ветка `main` не изменяется в ходе этой разработки.
