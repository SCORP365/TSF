# TSF Connect Bootstrap

Публичный загрузчик для безопасного получения приватного установщика TSF Connect.

## Назначение

Этот репозиторий предназначен только для bootstrap-слоя: QR-авторизации GitHub Device Flow, получения проверенного релиза из приватного репозитория и запуска единого установщика.

Основной код TSF Connect хранится отдельно и остаётся приватным:
[`SCORP365/TSF-Connect`](https://github.com/SCORP365/TSF-Connect).

## Текущий статус

**Разработка. Полный установщик ещё не готов.**

В репозитории подготовлены отдельные модули:
- `bootstrap/device_flow.py` — GitHub App Device Flow; токен остаётся в памяти.
- `bootstrap/private_source.py` — получение архива только по полному commit SHA, проверка SHA-256 и безопасное извлечение без ссылок и специальных файлов.
- `bootstrap/manifest.py` — проверка Ed25519-подписи манифеста через OpenSSL и проверка идентификатора приватного репозитория.

Загрузка и извлечение приватного архива пока не объединены с авторизацией в исполняемый сценарий. Публичный ключ доверия ещё не добавлен, подписанный релизный манифест в приватном репозитории ещё не подготовлен. Поэтому текущий код не является готовым установщиком и не должен использоваться на рабочем VPS.

Для отображения QR в терминале требуется системная утилита `qrencode`. Bootstrap не устанавливает её автоматически.

Локальные тесты: `python3 -m unittest discover -s tests -v`. GitHub Actions запускает этот набор при изменениях тестовой ветки.

## Безопасность

См. [документ по архитектуре и безопасности](docs/BOOTSTRAP-SECURITY.md).

- Не использовать PAT или Client Secret.
- Не загружать исполняемый код из плавающей ветки.
- Не извлекать и не запускать приватный код до проверки подписи манифеста и хеша архива.
- Не сохранять GitHub-токен на сервере.
- Не менять DNS, firewall, ISPmanager и посторонние службы в процессе авторизации.

## Ветки

Рабочая разработка ведётся в `test/bootstrap-qr`. Ветка `main` не изменяется.
